How trustworthy are the labels?

Sets A and B were labelled by three independent AI annotators that could only read each company's own website. To check them, the project author labelled a fixed random sample of 20 companies from set A without seeing the AI labels.

Agreement was weak. The disagreements follow one pattern: distributors and marketplaces that sell finished goods were labelled buyer by the human and not buyer by the AI, while factories that make products from the material were labelled the other way round. This points to two readings of "buyer" (a company that sells the product vs. a company that consumes the raw material), which the labelling guide resolves in favour of the second. A blind second round with the clarified definition was prepared (human_check_sheet_round2.csv, 20 new companies) but not carried out. Until it is, the real-world metrics above rest on AI labels whose agreement with a human has not been shown.

Error analysis and the v1 → v2 changes

After set A was scored with the frozen v1, its errors were analysed and the following general fixes were made. Because they were made after looking at set A, v2's numbers on set A (precision 81%, recall 63%, false-positive rate 39%) are optimistic and not used as a result. Set B was collected afterwards to test v2 without this bias.

  1. Supplier rule. 9 of the 15 buyers that v1 wrongly rejected were carpet and wool firms that mention the sheep farms they buy from. A farm mention now makes a company a supplier only if it has no processing, manufacturing or trading activity, or if it says it sells the raw material.
  2. Negation scope. "No irritation from the sheep's wool" had been read as denying wool. Negation now has to govern the material directly.
  3. About-the-company check. Blogs, associations and data firms describe other companies ("Havelock imports its wool…"). Activities and buying statements now count only in sentences that use "we/our" or the company's own name.
  4. Outsourced production. "Manufactured by Ringsted Dun" or "made by our partner workshops" is no longer read as the company's own manufacturing.
  5. Vocabulary. Plain "wool" (as in "British wool carpets") is now an ambiguous wool mention that can lead to Possible, never to Strong. "Steel wool" and "cotton wool" are excluded.

Limitations

  • English only. Polish, Hungarian, Italian and Japanese sites without English text are marked Insufficient Evidence, and partly English sites can wrongly fall to Not Relevant. This is the largest source of missed buyers. An optional multilingual LLM extractor is the planned fix.
  • Conservative by design. Recall on fresh data is 43%. The system prefers "not enough evidence" over a wrong lead.
  • Goose-only down producers are capped at Possible for Duck Down, while the annotators counted them as buyers.
  • One company, several websites. De-duplication works on web addresses, so one distributor with four sites counted as four leads in set A.
  • Blocklist gaps. bing.com and ebay.co.uk reached the analysis stage in set B.
  • Small samples. Set B has only 13 not-buyer companies, so its false-positive rate has a wide interval (4–42%).
  • Label quality. See the human check above.
  • Fictional set reuse. The fictional test split scored 100% after v2, but v2's changes were made with knowledge of its one remaining error, so the v1 figure (89% precision) is the one reported.

Reproduce

All data, labels and results are committed in the project's git repository (tag v2-tuned for the system used on set B).

cd backend
python -m pytest -q                          # 157 tests
python -m evaluation.run_eval                # fictional set  -> evaluation/RESULTS.md
python -m evaluation.audit                   # evidence audit -> evaluation/AUDIT.md
python -m evaluation.real_world score ai     # set A          -> evaluation/REAL_WORLD_RESULTS.md
python -m evaluation.real_world fresh-score  # set B          -> evaluation/FRESH_VALIDATION_RESULTS.md
python -m evaluation.real_world agreement    # human check    -> evaluation/LABEL_AGREEMENT.md
